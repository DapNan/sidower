SI DOWER — LANDING PAGE

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder si-dower-landing-page.
3. Klik dua kali index.html, atau jalankan dengan ekstensi Live Server di VS Code.

Struktur:
- index.html  : struktur halaman
- style.css   : tampilan, layout, dan responsive design
- script.js   : navigasi mobile, animasi scroll, tombol kembali ke atas

Catatan:
- Gambar saat ini memakai URL gambar Unsplash sehingga membutuhkan koneksi internet.
- Gambar, cerita, nama tradisi, data desa, dan informasi lokal masih berupa materi ilustratif/placeholder.
  Ganti dengan dokumentasi dan data terverifikasi dari Kecamatan Dawarblandong sebelum dipublikasikan.
- Navigasi menu utama yang lebih lengkap (Peta Digital, Ensiklopedia, Potensi Desa, Game Edukasi,
  Pendidikan, Galeri) sengaja belum dibuat sesuai permintaan; landing page dibuat terlebih dahulu.


UPDATE ENSIKLOPEDIA:
- Menu Ensiklopedia ditambahkan ke navigasi.
- Kartu desa dapat diklik untuk membuka bacaan detail.
- Ada kolom pencarian nama desa/cerita.
- Data kartu dan bacaan dikelola dari array villageData di script.js.
- Desa Talun sudah diberi contoh entri tentang serebeh. Detailnya masih berupa kerangka pengisian,
  jadi lengkapi bahan, cara pembuatan, sejarah, dan konteksnya berdasarkan wawancara/sumber lokal.
- Untuk menambah desa, salin satu objek data di villageData, lalu isi nama, kategori, image,
  summary, intro, dan sections. Gunakan URL foto yang dapat diakses browser.
- Kartu placeholder tanpa foto akan menampilkan panel "Tambahkan foto desa di script.js".
